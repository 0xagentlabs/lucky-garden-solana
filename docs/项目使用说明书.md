# 幸运花园项目使用说明书

## 项目简介

幸运花园是面向儿童的非付费抽奖小游戏，包含转盘抽奖与对对碰。两种界面共享同一条“每钱包每 UTC 日一次”的链上额度，并由 MagicBlock VRF 异步提供可验证随机数。奖品是链上结果记录，不发行或转移代币/NFT。

## 架构与目录

- `programs/lucky-garden`：Rust + Pinocchio 合约。
- `app`：Next.js App Router、TypeScript、Wallet Adapter dapp；`/admin` 为管理员配置页。
- `docs/ABI.md`：二进制 ABI、账户顺序与 PDA。
- `design-system/lucky-garden/MASTER.md`：儿童友好 UI 设计规范。

```bash

cd app
```

浏览器钱包切换到 Solana devnet。默认 RPC 是 `https://api.devnet.solana.com`，可通过 `NEXT_PUBLIC_RPC_URL` 覆盖。Program ID 当前仅为独立 keypair 的预留地址，尚未部署，原因见“部署状态”。

## 页面操作

1. 首页连接钱包，选择“转盘抽奖”或“对对碰”，点击开始；首次会同交易创建玩家 PDA。
2. 请求成功后页面显示交易摘要；VRF 回调完成后玩家账户变为 ready 并显示奖品。
3. 管理员访问 `/admin`，填写最多 8 个奖品；权重单位为基点且合计必须为 10000，签名后更新链上配置。

## 测试、构建与部署

```bash
cargo fmt --all -- --check
cargo test --workspace
cargo build-sbf --manifest-path programs/lucky-garden/Cargo.toml
cd app && pnpm test && pnpm build
solana config get
solana balance
solana program deploy target/deploy/lucky_garden.so --program-id target/deploy/lucky_garden-keypair.json
```

部署仅允许 devnet。部署前再次确认 RPC、钱包地址与余额；不得提交或输出 `target/deploy/lucky_garden-keypair.json`。部署后需由同一 CLI 钱包立即执行 InitializeConfig，避免首个设置者被抢占。

## 查询与排障

使用 `solana account <PDA> --output json` 回读账户，`solana confirm -v <SIGNATURE>` 查看日志。`InvalidSeeds` 表示 PDA 或 Program ID 不一致；`MissingRequiredSignature` 表示钱包/VRF identity 缺少签名；`InvalidArgument` 通常表示当天已抽或上一请求仍 pending；概率必须恰好合计 10000。VRF 请求确认不等于结果完成，pending 时应等待回调而非重复请求。
